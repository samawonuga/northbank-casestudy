# Third-Party Notices

This project is an interactive case study deck for Northbank, a fictional refinance product. It was built as a presentation-style React application for exploring customer funnel performance, conversion bottlenecks, segmentation signals, and strategic recommendations.

The code in this project is original and self-contained. It does not depend on any runtime assets from a separate `references` folder. Some visual patterns were inspired by public CodePen experiments and reimplemented here for motion, annotation, and layout effects. Those references are included below for attribution and licensing clarity.

## Project context

This repository is intended to be readable by someone who is not already familiar with the original design brief. The application is a fictional strategic deliverable, not a production financial product. The goal is to communicate an analysis story clearly and professionally.
